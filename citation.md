# Citation

Researchers using the Comprehensive Courts of Appeals Database (CCAD) should cite both the methods paper and the specific data release.

## Methods Paper

Sapiro-Gheiler, Eitan, and Jonathan P. Kastellec. 2026. "[Appealing to Large-Language-Model-as-Judge: Annotating and Analyzing the Universe of U.S. Appellate Opinions](/llm_appeals_09-2026.pdf)." Princeton University working paper.

```bibtex
@article{sapirogheiler_kastellec_ccad_methods,
  author = {Sapiro-Gheiler, Eitan and Kastellec, Jonathan P.},
  title  = {Appealing to Large-Language-Model-as-Judge: Annotating and Analyzing the Universe of U.S. Appellate Opinions},
  year   = {2026},
  note   = {Princeton University working paper}
}
```

## Dataset

Sapiro-Gheiler, Eitan, and Jonathan P. Kastellec. 2026. "[Comprehensive Courts of Appeals Database (CCAD)](https://doi.org/10.7910/DVN/XN2FVS)." Harvard Dataverse, V1. https://doi.org/10.7910/DVN/XN2FVS.

```bibtex
@misc{sapiro-gheiler_kastellec_ccad,
  author    = {Sapiro-Gheiler, Eitan and Kastellec, Jonathan P.},
  title     = {Comprehensive Courts of Appeals Database (CCAD)},
  year      = {2026},
  publisher = {Harvard Dataverse},
  version   = {V1},
  doi       = {10.7910/DVN/XN2FVS},
  url       = {https://doi.org/10.7910/DVN/XN2FVS}
}
```
